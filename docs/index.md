# dotshtuff

Documentation for the dotshtuff dotfiles template.

- Installation (bare repo + worktree): see the `README.md` on `main`
- [Shell configuration](shell-config.md): aliases, functions and variables
- Whitelisting files in `.gitignore`: add `!/path` rules; for directories, re-include each level
- Using the shtuff framework: see <https://github.com/rmayobre/shtuff>
